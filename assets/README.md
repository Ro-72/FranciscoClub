# Assets · Francisco’s Club

## `public/futbol-franciscos-club.jpg`

- Procedencia: generado con `mmx image generate`.
- Uso: sección editorial “Antes del primer toque” y metadata Open Graph.
- Prompt: escena editorial cinematográfica de una cancha de fútbol al anochecer, césped verde, luces doradas, sin texto, logos ni marcas inventadas.
- Revisión: inspeccionado visualmente antes de integrarlo.

Las credenciales de MiniMax no forman parte del repositorio. Para generar nuevas imágenes, usa la configuración local de mmx o `MINIMAX_API_KEY` fuera del código fuente.

## Pilares “Juega · Comparte · Pertenece”

Generados con `mmx image generate`, modelo `image-01`, en formato cuadrado de 1024 × 1024 px. Se revisaron visualmente y se seleccionaron estas versiones para las tarjetas de inicio:

- `public/assets/pilar-juega-v2.jpg`: primer toque en una cancha sintética sencilla al atardecer; energía, movimiento y realidad deportiva amateur.
- `public/assets/pilar-comparte-v3.jpg`: amigos con ropa deportiva informal compartiendo comida después del partido; cercanía y ritual social.
- `public/assets/pilar-pertenece.jpg`: jugador regresando de noche y siendo recibido en el club; comunidad y sensación de hogar.

Los prompts finales mantienen el contexto de Paucarpata, la estética editorial cinematográfica y la paleta negra, verde oscura y dorada. También solicitan composiciones centradas, sin texto, publicidad, marcas de agua ni identidad visual inventada. Las imágenes son conceptuales y no deben presentarse como fotografías documentales de las instalaciones o clientes reales.
